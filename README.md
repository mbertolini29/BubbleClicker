# Pecera-de-burbujas

rosario global game jam 25

Version de Unity 6000.0.24f1



Proyecto desarrollado durante la rosario global game jam 2025



En los tiempos libre se fue actualizando y mejorando el sistema de lógica del juego, para que sea escalable y tenga mínimo 3 niveles.



Clicker incremental con sistema de economía pasiva, upgrades de escenario y arquitectura modular preparada para escalar.



Enfoque en buenas prácticas, separación de responsabilidades y data-driven design con ScriptableObjects.
